# 실제 웹캠 전체 Workflow 검증표

**현재 상태: 미실시. 아래 표는 사용자 Windows PC에서 채울 검증 계획이다.**
실행일 / 이름 / GPU 메모리 / 드라이버 / Python / torch / llama-cpp-python / MediaPipe / best.pt 학습 실행명과 파일 해시를 먼저 기록한다. `python source\app.py --check` 출력과 학습 `results.csv`, `best.pt`를 함께 보관한다.

## 1. 식재료 → 메뉴 → 레시피

| 항목 | 실행 | 통과 기준 | 실제 결과 |
|---|---|---|---|
| 카메라 시작 | 일반 모드에서 웹캠 허용 | 실시간 영상, 캡처 가능 | 미실시 |
| YOLO 모델 | best.pt 복사, detector=yolo | 120클래스 이름 확인, 학습 모델과 일치 | 미실시 |
| 단일 재료 | 실제 1종 10회 촬영 | 오탐/미탐/중복을 횟수로 기록 | 미실시 |
| 다중 재료 | 3~5종 배치, 10회 촬영 | 정답 목록과 탐지 비교, 박스 위치 확인 | 미실시 |
| 어려운 상황 | 가림·어두움·포장·손 혼입 | 불확실 후보 확인, 정답을 추측해 추가하지 않는지 | 미실시 |
| 빈 사진 | 빈 조리대 촬영 | 빈 탐지/낮은 신뢰도. 오탐 발생 시 기록 | 미실시 |
| 수정·재촬영 | 재료 지우기/추가·뒤로 가기 | 확인 체크 해제, 수정 전 추천 무효화 | 미실시 |
| 메뉴 추천 | 확인한 실제 재료로 추천 | 한국어 메뉴 3개, 추가 재료 표기 | 미실시 |
| 레시피 생성 | 메뉴 선택 | JSON 오류 없음, 조리 단계·시간 일치 | 미실시 |
| 준비·조리 페이지 | 끝까지 이동 | 첫/마지막 경계, 타이머 표시 | 미실시 |
| 저장·복원 | 저장/불러오기/새로고침 | 재료·레시피·실행 중 종료시각 유지 | 미실시 |

탐지 정확도는 신뢰도 평균으로 대체하지 않는다. 정답이 붙은 독립 test split에서 `evaluate_detector.py`의 precision/recall/mAP50/mAP50-95와 클래스별 차이를 보고한다. 웹캠 평가는 별도 실물 목록으로 TP/FP/FN을 기록한다. 정확도 목표값은 이번 코드가 임의로 정하지 않았다.

## 2. 손동작 실물 검증

각 조건을 10회씩 수행하고 의도한 명령 성공 / 누락 / 의도하지 않은 실행을 기록한다.

| 조건 | 기대 결과 | 실제 결과 |
|---|---|---|
| 책 모드 👍 1초, 3초 유지 | 다음 페이지 1번만 이동 | 미실시 |
| 손 내린 뒤 👍 반복 | 추가 1페이지 이동 | 미실시 |
| 책 모드 👎 | 이전 페이지, 첫 페이지에서는 유지 | 미실시 |
| ✌️ | 타이머 모드로 전환, 안내도 전환 | 미실시 |
| ✊ 책 모드 | 단계 시간 설정, 타이머 모드 진입 | 미실시 |
| ☝️/🖐 | 현재 단위만큼 시간 증가/감소, 정지 상태 | 미실시 |
| 🤟 타이머 모드 | 1분/5분/1초/10초 순환 | 미실시 |
| 👍/👎/✊ 타이머 모드 | 시작/일시정지/초기화 | 미실시 |
| 타이머 동작 중 페이지 이동 | 진행 중인 타이머 시간·출처 유지 | 미실시 |
| 책 모드 🤟 → 1/2/3/4/5개 → 손 내리기 | 1~5분 각각 설정. 자동 시작 안 함 | 미실시 |
| 시퀀스 5초 초과 | 취소, 시간 변경 없음 | 미실시 |
| 손 없음·낮은 신뢰도·빠른 흔들림 | 반복 오동작 없음 | 미실시 |
| 탭 숨기기·카메라 중단·통신 지연 | 유지 시간 누적 초기화 | 미실시 |

## 3. 의도·되묻기·복합 입력

| 명령 | 기대 결과 | 실제 결과 |
|---|---|---|
| 다음 2페이지 | next 2, 실제 UI 이동 | 미실시 |
| 2페이지 넘겨 → 이전 | 되묻기 후 previous 2 | 미실시 |
| 타이머 설정 → 3분 | set 180, 정지 상태 | 미실시 |
| 타이머 30초 줄여 | adjust -30 | 미실시 |
| 이 단계 시간 설정 | 현재 단계 명시된 시간 사용, 없으면 질문 | 미실시 |
| 저쪽으로 해줘 / 버스 위치로 가 | 임의 페이지 이동 없음 | 미실시 |
| 다음 말고 이전 페이지 | 이전으로 이동 | 미실시 |
| 타이머 시작하지 마 | 실행 없음 | 미실시 |
| 함께 사용 ON, 엄지 아래 + 다음 페이지 | 텍스트 우선 다음 | 미실시 |
| 함께 사용 ON, 엄지 아래 + 이쪽 2페이지 | 이전 2 | 미실시 |
| 함께 사용 ON, 손 없음 + 이쪽 2페이지 | 되묻기 | 미실시 |
| 함께 사용 ON, 명령을 안 보냄 | 직접 포즈 실행 없음 | 미실시 |

JSON 도구 후보와 최종 도구, 실제 페이지·타이머 상태를 화면 로그에서 대조한다. API가 tool을 돌려준 사실과 실제 화면 실행 결과를 분리해서 기록한다.

## 시연 영상 추천 순서

1. 버전 1.3.0·일반 모드·실물 재료를 함께 보인다.
2. 촬영 → 박스/후보 확인 → 재료 수정·확인 → 메뉴 선택 → 레시피북 생성.
3. 👍로 페이지 이동, ✊로 시간 설정, 👍 시작, 👎 일시정지, ✊ 초기화.
4. 🤟 분 시퀀스, 되묻기 한 번, 텍스트와 손 충돌 한 번.
5. 실제 API 검증 결과와 미검증/실패 항목을 함께 제시한다.
