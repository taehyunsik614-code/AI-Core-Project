화면 크기 자동 맞춤 수정본 적용 방법

1. 기존 서버를 실행한 터미널에서 Ctrl+C로 종료합니다.
2. 이 압축을 풀면 바로 보이는 static 폴더를 찾습니다.
3. static 안의 index.html, style.css, app.js, core.js를 기존 프로젝트의 source\static에 덮어씁니다.
   예: C:\Users\SSAFY\Downloads\kitchen_book\kitchen_book\source\static
4. 기존 가상환경에서 프로젝트 폴더로 이동해 실행합니다.
   python source\app.py
5. 브라우저에서 http://127.0.0.1:8000 에 접속하고 Ctrl+F5를 누릅니다.
6. 위쪽에 01 재료 촬영 / 02 재료 확인 / 03 메뉴 추천 / 04 요리 시작이 보이면 적용된 것입니다.

이번 수정은 화면 파일에만 있습니다. 기존 models, .venv, Python 서버 파일은 바꾸지 않아도 됩니다.
첨부받은 원본의 다른 소스는 함께 보관했습니다. 현재 사용 중인 서버가 다른 버전이라면 static만 적용하세요.

책 모드: 엄지 위=다음, 엄지 아래=이전, 손바닥=타이머 모드, 검지=현재 단계 시간 설정 후 타이머 모드
타이머 모드: 엄지 위=시작/재개, 엄지 아래=일시정지, 손바닥=책 모드, 검지=시간 추가
감소/초기화/단위 변경은 타이머의 버튼을 사용합니다.
손을 약 0.9초 유지하고, 같은 동작을 다시 실행하려면 손을 잠시 내렸다가 보여 주세요.

전체 화면 스크롤 없이 단계별로 표시하고, 긴 설명은 이전/다음 페이지로 나눠 읽습니다.
실제 웹캠 인식률은 사용하는 PC에서 확인해 주세요.
